## 本周一句话

**不会写字的决策模型**上线：便宜到能塞进每个 agent 循环；社区第一波爆点是浏览器，最大争议是「零幻觉」被偷换成「判断总对」。

## 必看

### 1. 发车：RLCD + 类型化决策（官方）

- **钩子：** Diogo Almeida（InstructGPT / RLHF 相关）两年隐身后放出 Jev：Choice / Score / Noul，主张 20–200× 快、40–400× 便宜、输出免费。
- **链接：** [发车帖](https://x.com/CompleteSkeptic/status/2099925682726002904) · [发布博文](https://typesafe.ai/blog/introducing-system-one-models-and-jev) · [jaggedness](https://docs.typesafe.ai/model-jaggedness/jev-1.13.md)
- **标签：** `vendor-claim`
- **为何现在：** 整个赛道的原点；后续 demo 都从这里长出来。发车帖公开页曾见约 3270 万浏览量级（会变）。

### 2. Browser Use Ultrafast（本周传播之王）

- **钩子：** Jev 选操作 + DOM 元素，小 LLM 只在要打字时出场；公开演示 Google Flights 约 **7 秒 / $0.0039**。
- **链接：** [Gregor 帖](https://x.com/gregpr07/status/2100411066966749359) · [仓库 browser-use/jev-ultrafast](https://github.com/browser-use/jev-ultrafast) · [@browser_use](https://x.com/browser_use/status/2100411935938552136)
- **标签：** `structured-state-demo`（结构化 DOM/动作空间，不是像素端到端）
- **为何现在：** X 上最能带节奏的叙事——「决策层 + 小生成」比纯清单更火。

### 3. 网关三连：Vercel / OpenRouter / Cloudflare

- **钩子：** 不想排队等 TypeSafe waitlist 时，可走网关调 `typesafe-ai/jev` 一类路径（各家文档为准）。
- **链接：** [Vercel](https://x.com/vercel_dev/status/2100378959653507175) · [OpenRouter](https://x.com/OpenRouter/status/2100744709589316009) · [Rita / Cloudflare](https://x.com/ritakozlov/status/2100688919364845709)
- **标签：** `vendor-claim`（接入声明）
- **为何现在：** 把 Jev 从「实验室 API」推进成「agent 循环里的评价/路由按钮」。

### 4. 中文长帖：宝玉把 Jev 讲成人话

- **钩子：** 「智能判断函数 / 智能 if」——路由、分类、打分；并提醒极端加速倍数是最优情况。
- **链接：** https://x.com/dotey/status/2100109937237987823
- **标签：** `independent-eval`（第三方解读，非厂商评测）
- **为何现在：** 中文读者入门锚点；本雷达默认引用这篇而不是复读英文 launch。

### 5. 安全评审 / 数据扫表（工程向）

## 争议 / 红线

| 点 | 一句话 | 出处 |
| --- | --- | --- |
| **类型正确 ≠ 判断正确** | Schema 保证不会吐非法结构，不保证业务对 | HN + 官方 jaggedness + 中文长文 |
| **「JSON 分类器」帽子** | Every CEO：`LLM=补全 / Jev=JSON 分类器` | [@danshipper](https://x.com/danshipper/status/2100251499443998766) |
| **独立实测仍薄** | Every：777 次判断 &lt;0.7s、约 ¼¢；埋缺陷 **6/7**（对照 7/7） | OrcaRouter / remio 等中文综述 |
| **Demo 边界** | 航班 demo 火的同时，有人吐槽正经航班 API 缺失；结构化状态 ≠ 真视觉 CU | [@awlevin](https://x.com/awlevin/status/2100427922205209012) |
| **复现诚实** | Pac-Man 演示赢过一次，作者后来说复现不了 | [@ephraimduncan](https://x.com/ephraimduncan/status/2100554620254752981) |

**本周立场：** 速度/成本故事经得起第三方小样本；准确率与校准必须你自己用标注数据测。自动化前先做置信度分桶。
