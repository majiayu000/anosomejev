# Browser and computer automation

These projects use DOM elements, OCR text, or other structured observations. Check each implementation before assuming it operates directly on images.

- [jev-ultrafast](https://github.com/browser-use/jev-ultrafast) - Select browser actions and DOM elements with Jev; use a language model for text entry.
- [typesafe-computer-use](https://github.com/awlevin/typesafe-computer-use) - Use OCR text to help Jev select computer actions.

- [mobile-jev](https://github.com/droidrun/mobile-jev) - Android automation.
- [unclutter](https://github.com/kitze/unclutter) - Browser extension for classifying page clutter.

One successful demonstration does not establish reliability across websites. See [interactive applications](../patterns/realtime.md).
