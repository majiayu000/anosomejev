01 / 认识 Jev

先把输入、判断和执行分开。

INPUT状态 + 问题一张工单、一份文档
→
JUDGMENTJev返回结构化结果
→
CONTROL你的代码校验、规则、回退
→
OUTCOME建议或复核执行权限仍由系统管理
Choice

选哪个？

从命名选项中选择。例：工单应进入账单、技术还是其他队列。

Score

在哪个等级？

按明确的有序标准打分。例：从平静到生气，结果可以是小数。

Noul

条件成立吗？

返回 0–1 的概率。例：消息是否明确表达了紧急性。

格式正确 ≠ 判断正确。置信度不能直接当作正确率。示例阈值需要用自己的数据评估，高风险操作仍需授权与复核。官方置信度说明 ↗

接口说明依据 TypeSafe 文档与三种基础问题说明。
