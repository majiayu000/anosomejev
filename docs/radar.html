本周一句话

不会写字的决策模型上线：便宜到能塞进每个 agent 循环；社区第一波爆点是浏览器，最大争议是「零幻觉」被偷换成「判断总对」。

必看

1. 发车：RLCD + 类型化决策（官方）

  • 钩子： Diogo Almeida（InstructGPT / RLHF 相关）两年隐身后放出 Jev：Choice / Score / Noul，主张 20–200× 快、40–400× 便宜、输出免费。
  • 链接： 发车帖 · 发布博文 · jaggedness
  • 标签： vendor-claim
  • 为何现在： 整个赛道的原点；后续 demo 都从这里长出来。发车帖公开页曾见约 3270 万浏览量级（会变）。

2. Browser Use Ultrafast（本周传播之王）

  • 钩子： Jev 选操作 + DOM 元素，小 LLM 只在要打字时出场；公开演示 Google Flights 约 7 秒 / $0.0039。
  • 链接： Gregor 帖 · 仓库 browser-use/jev-ultrafast · @browser_use
  • 标签： structured-state-demo（结构化 DOM/动作空间，不是像素端到端）
  • 为何现在： X 上最能带节奏的叙事——「决策层 + 小生成」比纯清单更火。

3. 网关三连：Vercel / OpenRouter / Cloudflare

  • 钩子： 不想排队等 TypeSafe waitlist 时，可走网关调 typesafe-ai/jev 一类路径（各家文档为准）。
  • 链接： Vercel · OpenRouter · Rita / Cloudflare
  • 标签： vendor-claim（接入声明）
  • 为何现在： 把 Jev 从「实验室 API」推进成「agent 循环里的评价/路由按钮」。

4. 中文长帖：宝玉把 Jev 讲成人话

  • 钩子： 「智能判断函数 / 智能 if」——路由、分类、打分；并提醒极端加速倍数是最优情况。
  • 链接： https://x.com/dotey/status/2100109937237987823
  • 标签： independent-eval（第三方解读，非厂商评测）
  • 为何现在： 中文读者入门锚点；本雷达默认引用这篇而不是复读英文 launch。

5. 安全评审 / 数据扫表（工程向）

  • 钩子： Rauch 侧 fx 安全评审自称 p95 可快一截；Hamilton 用 DuckDB 扩展让 Jev 扫 CSV/Parquet 行分类。
  • 链接： rauchg · hamiltonulmer DuckDB
  • 标签： vendor-claim / single-run（公开帖数字，未当独立基准）
  • 为何现在： 说明 Jev 不只是玩具游戏，而是「便宜到能每步问一次」。
